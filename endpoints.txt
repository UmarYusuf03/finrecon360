Tenant identification

- The backend resolves the tenant from the authenticated user and an optional X-Tenant-Id header.
- If X-Tenant-Id is present, it must belong to the user; otherwise a deterministic fallback picks an active/admin tenant.
- All Phase 2-4 endpoints use this tenant resolution to open the correct tenant database and isolate data.
