### Task 2.1.1: Design Sync Audit Logic
**Purpose:** Verify POS End-of-Day made it into ERP books  
**Match Key:** ReferenceNumber / Order ID  
**Comparison:** POS → ERP by reference + date match  
**Success:** `SALES_VERIFIED` outcome (Level2 completion)

**Matching Rules:**
1. Get all committed POS records
2. Get all committed ERP records
3. Group POS by ReferenceNumber (normalized, case-insensitive)
4. For each POS group:
   - Find ERP record(s) with matching ReferenceNumber
   - If exact reference + date match: `MatchFound` (Level2 complete)
   - If reference matches but date drifts >15min: `Variance` (RequiresReview)
   - If no ERP reference exists: `MatchNotFound` (Pending)
5. Create ReconciliationMatchGroup with MatchLevel="Level2"

### Task 2.1.2: Implement ExecutePosLevel2SyncAuditAsync
**File:** `ReconciliationExecutionService.cs`

```csharp
private static async Task<ReconciliationExecutionResult> ExecutePosLevel2SyncAuditAsync(
    TenantDbContext tenantDb,
    Guid importBatchId,
    IReadOnlyList<ImportedNormalizedRecord> posRecords,
    CancellationToken ct)
{
    // 1. Load ERP records
    var erpRecords = await QueryCommittedBySourceType(tenantDb, "ERP", ct);
    
    // 2. Build ERP lookup by ReferenceNumber
    var erpByReference = erpRecords
        .Where(x => !string.IsNullOrWhiteSpace(x.ReferenceNumber))
        .GroupBy(x => x.ReferenceNumber!, StringComparer.OrdinalIgnoreCase)
        .ToDictionary(g => g.Key, g => g.ToList());
    
    // 3. For each POS record, find matching ERP
    var matched = 0;
    var exceptions = 0;
    
    foreach (var pos in posRecords)
    {
        var posRef = normalize(pos.ReferenceNumber);
        if (!erpByReference.TryGetValue(posRef, out var candidates)) {
            // No ERP match → MatchNotFound event
            exceptions++;
            continue;
        }
        
        // Score candidates by date proximity
        var bestCandidate = candidates
            .OrderBy(c => Math.Abs((pos.TransactionDate - c.TransactionDate).TotalSeconds))
            .FirstOrDefault();
        
        if (bestCandidate != null) {
            // Create Level2 match group
            matched++;
        } else {
            exceptions++;
        }
    }
    
    return BuildResult("POS", matched, exceptions, 0, 0, 0, 0m, "Level2 Sync Audit completed");
}
```

public async Task<IActionResult> ApproveTransaction(Guid id, [FromBody] ApproveRequest request)
{
    var txn = await _tenantDb.Transactions.FindAsync(id);
    
    // Check permission
    // Validate state is Pending
    
    // Apply cashout branching rule
    if (txn.TransactionType == TransactionType.CashOut && txn.Method == PaymentMethod.Card)
    {
        // Card cashout → needs bank match
        txn.TransactionState = TransactionState.NeedsBankMatch;
    }
    else if (txn.TransactionType == TransactionType.CashOut && txn.Method == PaymentMethod.Cash)
    {
        // Cash cashout → can post immediately
        txn.TransactionState = TransactionState.JournalReady;
    }
    else
    {
        // CashIn or other → JournalReady
        txn.TransactionState = TransactionState.JournalReady;
    }
    
    // Write state history
    await _auditLogger.LogAsync("TransactionApproved", ...);
    
    await _tenantDb.SaveChangesAsync();
    return Ok(txn);
}

### Task 2.3.1: Design Expense Match Logic
**Purpose:** Match approved card CASHOUT transactions against bank statement records  
**Match Key:** Auth Code / Transaction Reference  
**Comparison:** Approved Card Cashout ↔ Bank Statement by amount + date + ref

**Workflow:**
1. Find all transactions in `NeedsBankMatch` + `TransactionType.CashOut` + `Method.Card`
2. For each transaction, find BANK statement records matching:
   - Amount (exact or within tolerance)
   - TransactionDate (within ±1 day window)
   - ReferenceNumber or AuthCode match
3. If single strong match:
   - Create Level4 MatchGroup
   - Update transaction → JournalReady (unlock posting)
4. If multiple candidates or variance:
   - Create RequiresReview event
   - Leave in NeedsBankMatch for manual confirmation

### Task 2.3.2: Implement ExpenseMatchWorker
**File:** `finrecon360-backend-master/finrecon360-backend/Services/Workers/ExpenseMatchWorker.cs`

```csharp
public interface IExpenseMatchWorker
{
    Task<ExpenseMatchResult> ExecuteAsync(Guid tenantId, TenantDbContext tenantDb, CancellationToken ct);
}

public class ExpenseMatchWorker : IExpenseMatchWorker
{
    public async Task<ExpenseMatchResult> ExecuteAsync(Guid tenantId, TenantDbContext tenantDb, CancellationToken ct)
    {
        // 1. Load card cashout transactions in NeedsBankMatch state
        var cardCashouts = await tenantDb.Transactions
            .Where(t => t.TransactionState == TransactionState.NeedsBankMatch 
                && t.TransactionType == TransactionType.CashOut
                && t.Method == PaymentMethod.Card)
            .ToListAsync(ct);
        
        // 2. Load BANK records
        var bankRecords = await QueryCommittedBySourceType(tenantDb, "BANK", ct);
        
        // 3. For each card cashout, find bank match
        var matched = 0;
        var exceptions = 0;
        
        foreach (var txn in cardCashouts)
        {
            var candidates = bankRecords
                .Where(b => Math.Abs(b.NetAmount - txn.Amount) < 0.01m
                    && Math.Abs((txn.TransactionDate - b.TransactionDate).TotalDays) <= 1)
                .OrderBy(b => Math.Abs((txn.TransactionDate - b.TransactionDate).TotalSeconds))
                .ToList();
            
            if (candidates.Count == 1)
            {
                // Strong match → auto-confirm and move to JournalReady
                txn.TransactionState = TransactionState.JournalReady;
                // Create match group, logged event
                matched++;
            }
            else if (candidates.Count > 1)
            {
                // Ambiguous → RequiresReview
                // Create event, leave in NeedsBankMatch
                exceptions++;
            }
            else
            {
                // No match yet
                exceptions++;
            }
        }
        
        await tenantDb.SaveChangesAsync(ct);
        return new ExpenseMatchResult(matched, exceptions, "Expense Match completed");
    }
}
```

export class MatchService {
